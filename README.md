# Starters Practice Tests

Interactive practice tests in the style of the Pre A1 Starters exam (unofficial, original material).

- 3 complete tests
- Listening (4 parts, 20 questions) with browser text-to-speech audio
- Reading & Writing (5 parts, 25 questions)
- Automatic checking and score per part and per section
- Works offline: a single HTML file, no installation, no external libraries

## How to use

Open `index.html` in Chrome or Edge (best voice support), or visit the GitHub Pages link of this repository.

## Online version

Once GitHub Pages is enabled, the tests are available at:

`https://<your-username>.github.io/starters-practice-tests/`
